# Honey Money

Приложение читает новости российского рынка, отбирает важные и показывает, на какие бумаги они влияют. По любой бумаге можно запросить решение торгового модуля. Сделок приложение не совершает, а его ответы не являются инвестиционной рекомендацией.

Живая версия: https://ciolkovsky.ru

## Как проверить

Нужен Python 3.12 или Docker. Этот запуск работает без ключей и сети: на записанной ленте и записанных ответах модуля.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
NEWS_OFFLINE=1 .venv/bin/uvicorn honey_money.app:create_app --factory --port 8000
```

Или через Docker:

```bash
docker build -t honey-money . && docker run -e NEWS_OFFLINE=1 -p 8000:8000 honey-money
```

Откройте http://localhost:8000: появятся карточки бумаг. Кнопка «Спросить торговый модуль» работает для SBER, VTBR и LKOH, ответ подписан как записанный.

Тесты:

```bash
.venv/bin/python -m pytest
```

### Живой режим

Скопируйте `.env.example` в `.env`, заполните `STRATEGY_API_URL` и `STRATEGY_API_KEY`, а `NEWS_OFFLINE` оставьте пустым. Ключ жюри передаётся вместе с решением, в репозитории его нет. Затем:

```bash
set -a; source .env; set +a; .venv/bin/uvicorn honey_money.app:create_app --factory --port 8000
```

Первый сбор лент занимает около минуты. Решение модуля может занять до минуты, по ключу действует лимит запросов.

## Что открыто, а что нет

| Часть | Где |
|---|---|
| Сбор новостей из лент, журнал, отбор заголовков | `honey_money/news/` |
| Оценка новостей по бумагам: словарь или своя модель | `honey_money/scorer.py` |
| Веб-приложение и клиент торгового модуля | `honey_money/app.py`, `strategy_client.py`, `web/` |
| Торговая стратегия, модель решений, лимиты риска, полный пул источников и его веса | закрыты, работают на сервере за API |

Торговый модуль закрыт как коммерческая тайна. Здесь только демонстрационный набор из 10 лент с простыми весами, поэтому результаты отличаются от живой версии.

Записанные ответы лежат в `demo/replay.json`. Это настоящие ответы модуля от 01.11.2026, но новых решений в этом режиме не появляется.

## API торгового модуля

`POST {STRATEGY_API_URL}/v1/decide`, заголовок `X-API-Key`:

```json
{"ticker": "SBER", "headlines": [{"title": "…", "source": "interfax", "kind": "news"}]}
```

Ответ:

```json
{"ticker": "SBER", "action": "no_entry", "side": null, "confidence": 0.32,
 "explanation": "…", "session": "main", "decided_at": "2026-11-01T12:00:00+00:00", "source": "live"}
```

`action` принимает значения `consider_entry` или `no_entry`, `side` — `long`, `short` или `null`. Коды ошибок: 401 неверный ключ, 422 бумаги нет в списке, 429 лимит, 503 модуль занят или не ответил.
